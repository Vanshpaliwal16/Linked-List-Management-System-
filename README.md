# Linked List Management System

## Objective

A menu-driven Java console application for practicing linked-list data structures. The project implements both a Singly Linked List and a Doubly Linked List.

## Language Used

Java

## Features

### Singly Linked List
- Insert at beginning
- Insert at end
- Insert at position
- Insert after a node
- Insert before a node
- Delete from beginning
- Delete from end
- Delete from position
- Delete by value
- Search
- Update
- Display
- Count nodes
- Find maximum
- Find minimum
- Find middle element
- Reverse
- Sort
- Remove duplicates

### Doubly Linked List
- Insert at beginning
- Insert at end
- Insert at position
- Insert after a node
- Insert before a node
- Delete from beginning
- Delete from end
- Delete from position
- Delete by value
- Search
- Update
- Display forward
- Display backward
- Count nodes
- Find maximum
- Find minimum
- Find middle element
- Reverse
- Sort
- Remove duplicates

## How to Run

Open a terminal inside the `src` folder.

```bash
javac Main.java SinglyLinkedList.java DoublyLinkedList.java
java Main
```

## Time Complexity

| Operation | Typical Complexity |
|---|---|
| Insert at Beginning | O(1) |
| Insert at End | O(n) |
| Insert at Position | O(n) |
| Delete from Beginning | O(1) |
| Delete from End | O(n) |
| Search / Display / Count | O(n) |
| Find Min / Max | O(n) |
| Find Middle | O(n) |
| Reverse | O(n), O(1) extra space |
| Bubble Sort | O(n²) |
| Simple Remove Duplicates | O(n²) |
